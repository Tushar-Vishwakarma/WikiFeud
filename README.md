WikiFeud is a fun and engaging game inspired by Google Feud, which itself is inspired by the popular TV show "Family Feud." In WikiFeud, players are presented with partial search queries, and they must guess the most common completions based on Wikipedia's search suggestions. Feel free to update the game database and enjoy!


## Features

- **Autocomplete Suggestions**: Uses Wikipedia's search suggestions to provide autocomplete data.
- **Interactive Gameplay**: Players can input their guesses and see if they match the top suggestions.
- **Scoring System**: Keeps track of the player's score based on correct guesses.
- **Responsive Design**: Works on both desktop and mobile devices.
